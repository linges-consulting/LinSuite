# BREACH_CHECK_ENABLED=false. Loaded by core/security.py, which matches case-insensitively

# is refused on length before this file is consulted, so the millions of short entries in a
# breach corpus would add weight and no coverage. What remains is the set that actually
# defeats a length-only policy — keyboard walks, repeated words, long slogans and dates.
#
# This is the fallback, not the primary screen. With BREACH_CHECK_ENABLED=true (the

# that call cannot be made.

#   Raising the budget only ever appends rarer passwords.
